# My Budget Tracker

A simple front-end budget tracking page built with HTML and CSS.

## What I Built

- **Expense Table**: A structured table (`thead`/`tbody`) showing 5 sample expenses with Name, Amount, Category, and Date columns. Styled with borders, a colored header, and alternating row colors.
- **Add Expense Form**: Wrapped in a `<form>` element with a text input for name, number input for amount, and a `<select>` dropdown for category (Food, Transport, Rent, Entertainment, Other). Each input has a matching `id` for future JavaScript use.
- **Multimedia**: A logo image near the heading, and an embedded YouTube video with budgeting tips.
- **Interactive Element**: A collapsible "How to use this tracker" section using `<details>`/`<summary>`, plus hover effects on table rows and the button.
- **Advanced CSS Selectors**: Used a direct child selector, a descendant selector, a position-based pseudo-class (`nth-child`), a negation pseudo-class (`:not`), and a focus state (`:focus`).

## Files
- `index.html` — page structure and content
- `style.css` — all styling
